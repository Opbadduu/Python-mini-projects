# Rock Paper Scissors

A simple command-line Rock-Paper-Scissors game against the computer, built with Python.

## Features
- Play a single round against a randomized computer choice
- Input validation for invalid entries
- Clear win/lose/tie messages

## Requirements
No external libraries — uses Python's built-in `random` module.

## Usage
python rps_game.py
