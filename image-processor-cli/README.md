# Image Processor CLI

A simple command-line tool built with OpenCV to load an image, 
optionally convert it to grayscale, preview it, and save the result.

## Features
- Load an image from a given path
- View original or grayscale version
- Save the processed image with a custom filename
- Basic error handling (invalid path, missing extension)

## Requirements
pip install opencv-python

## Usage
python image_tool.py
